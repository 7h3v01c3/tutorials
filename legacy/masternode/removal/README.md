# Legacy Masternode Removal

This tutorial is for people who missed the now-deprecated **ease of use masternode removal** option over the last four years. That in-app option is **no longer available**. **Staking Vaults** replaced masternodes, so leftover `masternode.conf` files have to be removed by hand.

TheVoice spent his own time preserving this knowledge and building these tutorials so people can still dismantle a leftover masternode safely, without guessing which files to touch.
